# Ruby Example textures

Copyright © 2026 Hrajto Studio. All rights reserved.

These original 16×16 pixel textures are from HrajtyMC's Ruby Example mod. They may be displayed, resized and cached as part of the official HrajtyMC website. They are not Minecraft or Mojang textures.

- `ruby.png`: transparent ruby item texture.
- `ruby_block.png`: opaque ruby block texture.

Use `image-rendering: pixelated` when displaying these textures above their native size. No interpolation or texture modifications were applied to these copies.
